# Governance

FootnoteOne's maintainers are the people listed in `CODEOWNERS` (currently one); the goal is three named maintainers by the end of the Fall 2026 semester. Decisions that change a metric definition, the run format or the licence need an RFC issue open for seven days and approval from two maintainers, or from the sole maintainer while only one is listed. Everything else merges on one approving review.

The project will not add a hosted tier, telemetry or a contributor licence agreement. If maintainers leave, the remaining maintainers name replacements; if none remain, the last maintainer archives the repository with a notice pointing to the published measurement dataset.
